Sistema privado de inventario de dispositivos físicos de almacenamiento

Organiza archivos físicos HDD, SSD, USB y LTO mediante etiquetas compactas. Las contraseñas de cifrado, notas, instantáneas de archivos y metadatos permanecen en una base local protegida por separado.

Generación de etiquetas físicas

Cinco atributos se codifican en un orden específico de la base; cada bloque lleva un carácter de comprobación dependiente de una clave.

La etiqueta es un identificador seudónimo, no texto cifrado. Pueden permanecer patrones estadísticos.

Los secretos requieren cifrado autenticado

Las bases PQC modernas combinan una envoltura de clave OpenPGP firmada con ML-KEM/Kyber y una carga AEAD XChaCha20-Poly1305.

Las etiquetas físicas son identificadores, no texto cifrado. La calculadora y la esteganografía no sustituyen el cifrado.

OpenPGP + ML-KEM

GPGME gestiona claves y verifica firmas. Requiere GnuPG 2.5+; las firmas no son poscuánticas.

XChaCha20-Poly1305

AEAD de .dpdb con vinculación AAD de cabecera y relleno por tamaños.

Estructura de la base cifrada

Esquema conceptual de Argon2id/XChaCha20-Poly1305; no se muestran otros modos de protección de claves.

Las firmas OpenPGP no son poscuánticas; los ID de las claves destinatarias pueden ser visibles.

Almacenamiento esteganográfico

El diagrama ilustra la inserción y extracción de una base cifrada en un archivo portador.

La esteganografía no sustituye al cifrado. La inserción LSB/DCT puede detectarse y la transcodificación puede destruir la carga útil.

01Instalar dependencias

sudo apt install git build-essential pkg-config \
  libgtk-3-dev libglib2.0-dev libgpgme-dev \
  libsodium-dev libcjson-dev libjpeg-dev libwebp-dev \
  libpango1.0-dev liblzma-dev imagemagick \
  bluez fonts-dejavu-core

02Clonar y compilar

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
chmod +x ./build.sh
./build.sh

03Iniciar DiskPass

diskpass

Ejecute build.sh como usuario normal, sin sudo. Se necesita GPGME ≥ 1.24.1; para PQC también se requiere GnuPG 2.5+ con ML-KEM. Es posible que las distribuciones antiguas no incluyan estas versiones.
