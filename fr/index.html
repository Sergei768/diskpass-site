Construction de l’étiquette physique

Cinq attributs sont encodés selon un ordre propre à la base ; chaque bloc reçoit un caractère de contrôle calculé avec une clé.

L’étiquette est un identifiant pseudonyme, pas un texte chiffré. Des motifs statistiques peuvent subsister.

Les secrets exigent un chiffrement authentifié

Les bases PQC modernes associent une enveloppe de clé OpenPGP signée utilisant ML-KEM/Kyber et une charge utile AEAD XChaCha20-Poly1305.

Les étiquettes physiques sont des identifiants, pas du texte chiffré. La calculatrice et la stéganographie ne remplacent pas le chiffrement.

OpenPGP + ML-KEM

GPGME gère les clés et signatures. GnuPG 2.5+ est nécessaire ; les signatures ne sont pas post-quantiques.

XChaCha20-Poly1305

AEAD pour .dpdb avec liaison AAD de l’en-tête et remplissage par classes de taille.

Structure de la base chiffrée

Schéma conceptuel Argon2id/XChaCha20-Poly1305 ; les autres modes de protection des clés ne sont pas représentés.

Les signatures OpenPGP ne sont pas post-quantiques ; les identifiants des clés destinataires peuvent rester visibles.

Stockage stéganographique

Ce diagramme illustre l’insertion et l’extraction d’une base chiffrée dans un fichier porteur.

La stéganographie ne remplace pas le chiffrement. L’insertion LSB/DCT peut être détectée et le transcodage peut détruire la charge utile.

Compilation depuis les sourcesInstructions vérifiées dans README et build.sh · Debian / UbuntuAfficher les commandes de compilation

01Installer les dépendances

sudo apt install git build-essential pkg-config \
  libgtk-3-dev libglib2.0-dev libgpgme-dev \
  libsodium-dev libcjson-dev libjpeg-dev libwebp-dev \
  libpango1.0-dev liblzma-dev imagemagick \
  bluez fonts-dejavu-core

02Cloner et compiler

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
chmod +x ./build.sh
./build.sh

03Lancer DiskPass

diskpass

Exécutez build.sh comme utilisateur normal, sans sudo. GPGME ≥ 1.24.1 est nécessaire ; le mode PQC requiert également GnuPG 2.5+ avec ML-KEM. Les anciennes distributions peuvent ne pas proposer ces versions.
