Приватная система учёта физических накопителей

Упорядочивайте архивы HDD, SSD, USB и LTO при помощи компактных физических тегов. Храните пароли шифрования, заметки, файловые снимки и сведения о носителях в отдельно защищённой локальной базе.

Порядок в архиве физических носителей

Физическая идентификация

Теги из пяти полей, индивидуальная схема базы, справочники типов и ёмкостей, случайная соль для каждого носителя.

Зашифрованное хранилище

Пароли томов, методы шифрования, заметки и соответствия тегов в локальном контейнере .dpdb.

Файловый каталог

Снимки структуры файлов, просмотр каталогов и поиск содержимого архивных носителей без облака.

Интерфейс калькулятора

Опциональная маскировка окна рабочим калькулятором с отдельным кодом доступа и защитой настроек.

Формирование физического тега

Пять атрибутов кодируются по схеме конкретной базы; каждый блок получает контрольный символ с секретным ключом.

Тег — псевдонимный идентификатор, а не шифртекст. Структурные закономерности могут сохраняться.

Секреты защищает аутентифицированное шифрование

Современная PQC-база использует два уровня: подписанный OpenPGP-конверт ключа ML-KEM/Kyber и аутентифицированный XChaCha20-Poly1305 payload. При чтении и сохранении проверяется политика защиты.

Физические теги — идентификаторы, а не шифртекст. Калькулятор и стеганография не заменяют шифрование.

OpenPGP + ML-KEM

GPGME управляет ключами, конвертом и проверкой подписи. Для PQC требуется GnuPG 2.5+ с ML-KEM; подпись не становится постквантовой.

XChaCha20-Poly1305

Полезная нагрузка .dpdb шифруется с AEAD, привязкой заголовка через AAD и дополнением до диапазонов размеров.

Устройство зашифрованной базы

Концептуальная схема Argon2id/XChaCha20-Poly1305; другие режимы защиты ключей здесь не показаны.

Подпись OpenPGP не постквантовая; ID ключей получателей могут оставаться видимыми.

Стеганографическое хранение

Схема показывает встраивание и извлечение зашифрованной базы из файла-контейнера.

Стеганография не заменяет шифрование. Встраивание LSB/DCT может быть обнаружено, а перекодирование способно уничтожить payload.

Сборка из исходниковКоманды из README и build.sh проекта · Debian / UbuntuПоказать команды сборки

01Установите зависимости

sudo apt install git build-essential pkg-config \
  libgtk-3-dev libglib2.0-dev libgpgme-dev \
  libsodium-dev libcjson-dev libjpeg-dev libwebp-dev \
  libpango1.0-dev liblzma-dev imagemagick \
  bluez fonts-dejavu-core

02Скачайте и соберите

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
chmod +x ./build.sh
./build.sh

03Запустите DiskPass

diskpass

Запускайте build.sh от обычного пользователя, без sudo. Для сборки необходим GPGME ≥ 1.24.1, а для PQC-режима — GnuPG 2.5+ с ML-KEM. В старых дистрибутивах нужных версий может не быть.
