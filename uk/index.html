Приватна система обліку фізичних накопичувачів

Впорядковуйте архіви HDD, SSD, USB і LTO за компактними фізичними мітками. Паролі шифрування, нотатки, файлові знімки й метадані зберігайте в окремо захищеній локальній базі.

ЗавантаженняПереглянути репозиторій

Зрозумілий архів фізичних носіїв

Фізична ідентифікація

П’ять полів, окрема схема кожної бази, словники типів і місткостей та випадкова сіль носія.

Зашифроване сховище

Паролі томів, методи шифрування, нотатки та відповідності міток у локальному .dpdb.

Файловий каталог

Знімки файлової структури, перегляд каталогів і пошук в офлайновому архіві.

Режим калькулятора

Необов’язкове маскування інтерфейсу калькулятором з окремим кодом.

Формування фізичного тегу

П’ять атрибутів кодуються за схемою конкретної бази; кожен блок отримує контрольний символ на основі секретного ключа.

Тег — псевдонімний ідентифікатор, а не шифротекст. Структурні закономірності можуть зберігатися.

Секрети захищає автентифіковане шифрування

Сучасний PQC-контейнер використовує підписаний OpenPGP-конверт ML-KEM/Kyber та XChaCha20-Poly1305 для даних із перевіркою політики.

Фізичні мітки — ідентифікатори, а не шифротекст. Калькулятор і стеганографія не замінюють шифрування.

OpenPGP + ML-KEM

GPGME керує ключами й перевіряє підписи. Потрібен GnuPG 2.5+; підпис не є постквантовим.

XChaCha20-Poly1305

AEAD-захист бази .dpdb, AAD-прив’язка заголовка та доповнення розміру.

Структура зашифрованої бази

Концептуальна схема Argon2id/XChaCha20-Poly1305; інші режими захисту ключів тут не показані.

Підпис OpenPGP не є постквантовим; ID ключів одержувачів можуть залишатися видимими.

Стеганографічне зберігання

Схема показує вбудовування та витягування зашифрованої бази з файла-контейнера.

Стеганографія не замінює шифрування. Вбудовування LSB/DCT може бути виявлене, а перекодування здатне знищити payload.

Збирання з вихідного кодуКоманди з README та build.sh проєкту · Debian / UbuntuПоказати команди збирання

01Встановіть залежності

sudo apt install git build-essential pkg-config \
  libgtk-3-dev libglib2.0-dev libgpgme-dev \
  libsodium-dev libcjson-dev libjpeg-dev libwebp-dev \
  libpango1.0-dev liblzma-dev imagemagick \
  bluez fonts-dejavu-core

02Завантажте та зберіть

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
chmod +x ./build.sh
./build.sh

03Запустіть DiskPass

diskpass

Запускайте build.sh від звичайного користувача, без sudo. Для збирання потрібен GPGME ≥ 1.24.1, а для PQC — GnuPG 2.5+ з ML-KEM. У старих дистрибутивах потрібних версій може не бути.
