實體儲存裝置的私密管理系統

以精簡的實體標籤整理 HDD、SSD、USB 和 LTO 檔案庫。加密密碼、註記、檔案快照與媒體資訊皆存於獨立保護的本機資料庫。

實體識別

五欄位標籤、每庫獨立排列、媒體與容量字典、每顆磁碟隨機鹽。

加密憑證庫

將磁碟密碼、加密方法、註記及標籤對應存入本機 .dpdb。

檔案目錄

建立檔案快照，離線瀏覽資料夾並搜尋歸檔內容。

計算機介面

可選的計算機偽裝，透過獨立存取碼保護設定。

實體標籤產生

五項屬性依資料庫專屬的區塊順序編碼，每個區塊附有以密鑰計算的檢查字元。

標籤是化名識別碼，而非密文；區塊模式仍可能洩漏統計資訊。

憑證必須受到驗證式加密保護

現代 PQC 資料庫使用已簽署的 ML-KEM/Kyber OpenPGP 金鑰封裝，並以 XChaCha20-Poly1305 驗證與加密內容。

實體標籤是識別碼，而非密文。計算機介面與隱寫載體無法取代加密。

OpenPGP + ML-KEM

GPGME 管理金鑰及驗證簽章。PQC 需要 GnuPG 2.5+；簽章並非後量子簽章。

XChaCha20-Poly1305

.dpdb 使用 AEAD、AAD 標頭綁定及長度分桶填補。

加密資料庫結構

Argon2id/XChaCha20-Poly1305 概念流程；其他金鑰保護模式未在此圖中呈現。

OpenPGP 簽章不具後量子安全性；收件者密鑰 ID 可能可見。

隱寫儲存

此圖說明如何在載體檔案中嵌入及提取加密資料庫。

隱寫不等於加密。LSB/DCT 嵌入可能被偵測到，轉碼也可能破壞負載。

從原始碼建置依照專案 README 與 build.sh 整理 · Debian / Ubuntu顯示建置指令

01安裝建置相依套件

sudo apt install git build-essential pkg-config \
  libgtk-3-dev libglib2.0-dev libgpgme-dev \
  libsodium-dev libcjson-dev libjpeg-dev libwebp-dev \
  libpango1.0-dev liblzma-dev imagemagick \
  bluez fonts-dejavu-core

02複製並建置

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
chmod +x ./build.sh
./build.sh

03啟動 DiskPass

diskpass

請以一般使用者執行 build.sh，不要使用 sudo。建置需要 GPGME ≥ 1.24.1；PQC 功能需要支援 ML-KEM 的 GnuPG 2.5+。較舊的發行版可能缺少所需版本。
