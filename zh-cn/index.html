物理存储设备的私密管理系统

用紧凑的物理标签管理 HDD、SSD、USB 与 LTO 档案。加密密码、备注、文件快照和介质元数据存储在独立保护的本地数据库中。

可检索的物理存储档案

物理介质识别

五字段标签、每库独立顺序、介质和容量字典、每磁盘随机盐。

加密凭据库

将磁盘密码、加密方式、备注及标签映射保存在本地 .dpdb 中。

文件索引

生成文件结构快照，离线浏览目录并搜索归档文件。

计算器伪装

可选的计算器界面，使用独立访问码保护设置。

物理标签生成

五项属性按数据库专属的区块顺序编码，每个区块附带基于密钥的校验字符。

标签是化名标识符，并非密文；区块模式仍可能泄露统计信息。

凭据依赖认证加密保护

现代 PQC 数据库采用已签名的 ML-KEM/Kyber OpenPGP 密钥封装，并通过 XChaCha20-Poly1305 保护数据库内容。

物理标签是标识符，而不是密文。计算器界面和隐写载体不能替代加密。

OpenPGP + ML-KEM

GPGME 处理密钥和签名验证。PQC 需要 GnuPG 2.5+；现有签名并非后量子签名。

XChaCha20-Poly1305

.dpdb 内容采用 AEAD、AAD 头绑定与长度分桶填充。

加密数据库结构

Argon2id/XChaCha20-Poly1305 概念流程；其他密钥保护模式未在此图中展示。

OpenPGP 签名不具备后量子安全性；收件人密钥 ID 可能可见。

隐写存储

该图说明如何在载体文件中嵌入和提取加密数据库。

隐写并不等于加密。LSB/DCT 嵌入可能被检测到，转码也可能破坏负载。

从源代码构建根据项目 README 与 build.sh 整理 · Debian / Ubuntu查看构建命令

01安装构建依赖

sudo apt install git build-essential pkg-config \
  libgtk-3-dev libglib2.0-dev libgpgme-dev \
  libsodium-dev libcjson-dev libjpeg-dev libwebp-dev \
  libpango1.0-dev liblzma-dev imagemagick \
  bluez fonts-dejavu-core

02克隆并构建

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
chmod +x ./build.sh
./build.sh

03启动 DiskPass

diskpass

请以普通用户运行 build.sh，不要使用 sudo。构建要求 GPGME ≥ 1.24.1；PQC 功能需要支持 ML-KEM 的 GnuPG 2.5+。旧版发行版可能缺少所需版本。
