물리적 저장 장치의 비공개 목록 관리 시스템

HDD, SSD, USB 및 LTO 보관함을 짧은 물리 태그로 관리하세요. 암호화 비밀번호, 메모, 파일 스냅샷과 매체 정보는 별도로 보호된 로컬 데이터베이스에 저장됩니다.

검색 가능한 물리 저장매체 보관함

물리 매체 식별

5개 필드, 데이터베이스별 순서, 종류 및 용량 사전, 매체별 무작위 솔트.

암호화 보관함

비밀번호, 암호화 방식, 메모, 태그 매핑을 로컬 .dpdb에 저장.

파일 인덱스

파일 트리 스냅샷, 디렉터리 탐색 및 오프라인 검색.

계산기 모드

독립 접근 코드로 보호되는 선택적 계산기 인터페이스.

물리 태그 생성

다섯 속성은 데이터베이스별 블록 순서로 인코딩되며, 각 블록에는 비밀 키 기반 검사 문자가 추가됩니다.

태그는 가명 식별자이지 암호문이 아닙니다. 블록의 통계적 패턴은 남을 수 있습니다.

비밀은 인증된 암호화로 보호합니다

현대 PQC 데이터베이스는 서명된 ML-KEM/Kyber OpenPGP 키 봉투와 XChaCha20-Poly1305 AEAD 페이로드를 사용합니다.

물리적 태그는 암호문이 아닌 식별자입니다. 계산기 인터페이스나 스테가노그래피는 암호화를 대체하지 않습니다.

OpenPGP + ML-KEM

GPGME가 키와 서명을 검증합니다. GnuPG 2.5+ 필요, 서명 자체는 양자내성이 아닙니다.

XChaCha20-Poly1305

.dpdb 인증 암호화, AAD 헤더 바인딩, 크기 버킷 패딩.

암호화된 데이터베이스 구조

Argon2id/XChaCha20-Poly1305 개념 흐름입니다. 다른 키 보호 모드는 이 그림에 포함되지 않습니다.

OpenPGP 서명은 양자 내성 서명이 아니며 수신자 키 ID가 노출될 수 있습니다.

스테가노그래픽 저장

이 그림은 캐리어 파일에서 암호화된 데이터베이스를 삽입하고 추출하는 흐름을 보여줍니다.

스테가노그래피는 암호화를 대체하지 않습니다. LSB/DCT 삽입은 탐지될 수 있고 트랜스코딩으로 payload가 손상될 수 있습니다.

01빌드 의존성 설치

sudo apt install git build-essential pkg-config \
  libgtk-3-dev libglib2.0-dev libgpgme-dev \
  libsodium-dev libcjson-dev libjpeg-dev libwebp-dev \
  libpango1.0-dev liblzma-dev imagemagick \
  bluez fonts-dejavu-core

02클론 및 빌드

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
chmod +x ./build.sh
./build.sh

03DiskPass 실행

diskpass

build.sh는 sudo 없이 일반 사용자로 실행하세요. GPGME ≥ 1.24.1이 필요하며 PQC에는 ML-KEM을 지원하는 GnuPG 2.5+가 필요합니다. 오래된 배포판에서는 해당 버전을 제공하지 않을 수 있습니다.
